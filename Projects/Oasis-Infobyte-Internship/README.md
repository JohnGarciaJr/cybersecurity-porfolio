# Oasis Infobyte – Cybersecurity Internship (1 Month)

This repository contains all tasks, reports, scripts, and documentation completed as part of the **Oasis Infobyte Cybersecurity Internship**. The internship requires completing **at least four tasks**, each with its own deliverables such as scripts, configuration files, screenshots, reports, and demo videos.

🔗 **Full Internship Repository:**  
[View Repository](https://github.com/JohnGarciaJr/oasis-infobyte-cybersecurity-internship)

The tasks in this repository demonstrate foundational cybersecurity skills across areas including:

- Network scanning (Nmap)
- Firewall configuration (UFW)
- Web application vulnerabilities (DVWA SQL Injection)
- Vulnerability scanning (Nikto)
- Network traffic analysis (Wireshark)
- Security research and reporting
