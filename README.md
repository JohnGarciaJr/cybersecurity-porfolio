# Cybersecurity & GRC Portfolio

Welcome to my Cybersecurity & Governance, Risk, and Compliance (GRC) portfolio.  
This repository showcases hands‑on, documentation‑driven work aligned with real‑world security programs and industry frameworks such as **NIST CSF**, **ISO 27001**, and **SOC 2**.

The goal of this portfolio is to demonstrate:
- Clear, professional security documentation  
- Practical GRC skills  
- Framework alignment and control mapping  
- Risk analysis and prioritization  
- Governance‑level policy development  
- Audit readiness and evidence structure  

This repo is organized into the three pillars of GRC.
